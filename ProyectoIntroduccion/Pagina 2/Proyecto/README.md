# Mundo Pokémon

Proyecto de Desarrollo Web (HTML5, CSS3 y JavaScript), sin mezclar lenguajes.

## Estructura
```
Proyecto/
├── index.html          # Página de inicio
├── pags/               # Páginas internas
│   ├── pagina2.html    #   Pokédex (tabla, listas, buscador)
│   ├── multimedia.html #   Galería de imágenes
│   └── registro.html   #   Formulario
├── css/estilos.css
├── js/main.js
└── imgs/               # Imágenes y favicon
```

## Requerimientos no funcionales
- Rutas relativas
- Directorios organizados
- Etiquetas semánticas (header, nav, main, section, article, aside, footer, figure)
- Repositorio Git
- No mezclar lenguajes: sin `style=""` ni `onclick` en el HTML; el CSS está en `css/` y el JavaScript en `js/`

## Requerimientos funcionales
- Favicon
- Responsive (menú desplegable en móvil, rejillas fluidas)
- Multimedia: imágenes
- Navegación entre diferentes páginas
- Tablas, listas y formularios
- CSS
- Funcionalidad con JS (buscador y filtro, validación de formulario, menú móvil)
